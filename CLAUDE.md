# CLAUDE.md — Sav waitlist landing

This file gives Claude Code context when it opens this repo.

## What this is

A single-page Next.js 16 marketing site for **Sav**, a parenting-coach
waitlist. Yetty Williams (founder of LagosMums) routes traffic to this
site from her other properties. Visitors enter an email + optional
details and join the waitlist. After signing up, they see a WhatsApp
CTA so Yetty can talk to the first cohort directly.

## Architecture

- **Next.js 16 App Router**, **React 19**, **Tailwind CSS 4**
- Entire homepage is `src/app/page.tsx` (a `"use client"` component for
  the form state; sections are co-located helper functions)
- Server action in `src/app/actions.ts` validates submissions with zod
  and currently `console.log`s them — the Supabase insert is written out
  as a commented block ready to enable
- All swappable links/copy live in `src/lib/config.ts`. Env vars override:
  `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_WHATSAPP_URL`
- SEO assets are generated by Next conventions:
  - `src/app/icon.tsx` — favicon (dynamic SVG → PNG)
  - `src/app/apple-icon.tsx` — touch icon
  - `src/app/opengraph-image.tsx` — share preview (1200×630)
  - `src/app/twitter-image.tsx` — re-exports the OG image
  - `src/app/robots.ts`, `src/app/sitemap.ts`
- `next.config.ts` permanently redirects `/sav` → `/` (historical route)

## How to wire Supabase

1. Run `supabase/sav_waitlist.sql` in the Supabase SQL editor
2. Set `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` env vars
3. `npm install @supabase/supabase-js`
4. In `src/app/actions.ts`, replace the `// ─── Supabase hookup goes here`
   `console.log` with the (commented) insert block right above it

## Conventions

- No comments in code unless the *why* is non-obvious — naming carries
  intent
- Tailwind utility classes inline (no CSS modules)
- The amber/cream palette (`#FBF7F2` background, `text-amber-700`
  accents) is hand-picked — keep it consistent
- The hero phone mockup is hand-built in HTML/CSS, not an image. Edit
  the chat bubbles in `function PhoneMockup()`
